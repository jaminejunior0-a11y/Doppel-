# Doppel-

 **A lightweight Android utility that demonstrates advanced system interoperability concepts.**

Doppel is an educational research project exploring the boundaries of Android's compatibility layers and system service architecture. It provides a framework for understanding how modern Android applications interact with system services, with a focus on legacy compatibility modes and native code integration.

## Features
- Native C++ library integration via JNI
- Legacy Android API compatibility (minSdk 16)
- Modern AndroidX UI components
- Educational examples of system service interaction
- Research-grade code for understanding Android internals

## Purpose
This project exists solely for educational and research purposes. It demonstrates:
- How Android maintains backward compatibility
- Native code integration patterns
- System service architecture exploration
- Legacy API behavior in modern Android
